## Catatan Penggunaan

- **Ya** ✓ = Item diperiksa dan dinyatakan baik / sesuai standar
- **Tidak** ✗ = Item diperiksa dan ditemukan masalah / tidak sesuai — **WAJIB** diisi catatan
- **N/A** = Item tidak berlaku untuk tipe mesin ini

> Template ini dapat disesuaikan (ditambah/dikurangi itemnya) untuk masing-masing tipe mesin di CMMS SIGMA.
